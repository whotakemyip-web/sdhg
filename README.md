# DynamicIsland MD3 — "остров" для Windows в стиле Material You

Плавающий виджет сверху экрана, похожий на Dynamic Island с iPhone, но для
Windows, собранный на Electron и оформленный в стиле Material Design 3
(Material You) — с несколькими цветовыми палитрами, светлой/тёмной темой и
набором мини-функций.

## Что нового (v1.1): Flower UI, центр управления, настройки внутри острова

- **Flower UI** — пастельные палитры (Sakura, Lavender, Peach, Mint), большие скругления, цветочные
  украшения и вращающийся цветок в капсуле. Есть светлая, тёмная и «Авто» (по теме Windows) версии.
  Палитра **Monet** (из обоев) в стиле Flower автоматически смягчается до пастели. Переключатель
  **Flower / Classic MD3** — в Настройки → Оформление.
- **Настройки внутри острова** — вкладка «Настройки» с подвкладками Оформление / Остров / Система.
  Остров раскрывается по клику на капсулу (плавная анимация окна), второго окна нет.
  `Esc` сворачивает, `Ctrl+Alt+I` раскрывает/сворачивает из любого места, есть опция
  «сворачивать при потере фокуса».
- **Центр управления** (вкладка «Центр»): плитки Wi-Fi / Bluetooth / «Не беспокоить» / «Не засыпать» /
  тёмная тема / скриншот (реальное состояние читается при открытии), ползунки **яркости** и **громкости**,
  карточка **«Сейчас играет»** (название, исполнитель, обложка, прогресс — через системные медиа-сессии
  Windows), CPU/RAM с графиком, быстрые действия и инструменты (Диспетчер задач, Калькулятор, Параметры,
  Проводник, Вырезка).
- **Живая капсула**: в свёрнутом виде показывает таймер фокуса или трек, который играет.
- **Фокус-таймер** с пресетами 15/25/45/60 минут.

### Как это работает и что может не сработать

- Громкость — Core Audio (`IAudioEndpointVolume`) через PowerShell, права администратора не нужны.
- Яркость — WMI (`WmiMonitorBrightnessMethods`): **только встроенные экраны** ноутбуков/моноблоков;
  на внешних мониторах ползунок отключается.
- «Сейчас играет» — долгоживущий `powershell.exe` с WinRT (`GlobalSystemMediaTransportControls`),
  нужна Windows 10 1809+. Если процесс не поднимается, после нескольких попыток карточка покажет сообщение.
- «Не беспокоить» — выключает баннеры уведомлений ключом реестра пользователя
  (`PushNotifications\ToastEnabled`); **экспериментально**, поведение зависит от сборки Windows.
- «Не засыпать» — `powerSaveBlocker` Electron.
- Скрипты для громкости/яркости/«сейчас играет» **не запускались на реальной Windows при разработке** —
  проверьте руками (чек-лист ниже).

**Чек-лист после первого запуска:** раскрыть/свернуть; сменить стиль и палитры; ползунок громкости и
кнопка mute; ползунок яркости (ноутбук); запустить музыку — трек и обложка в карточке и в капсуле;
плитки Wi-Fi/Bluetooth (UAC); «Не засыпать»; `Ctrl+Alt+I`; Monet.

## Что внутри

- **Сворачиваемый "островок"**: маленькая капсула сверху экрана → клик
  раскрывает полноценную панель.
- **Системная статистика**: загрузка CPU и RAM (кольцевые индикаторы),
  аптайм, имя хоста, заряд батареи — реальные данные из `os`/`navigator.getBattery`.
- **Реальные медиа-клавиши**: Play/Pause, Next, Prev, Volume Up/Down/Mute —
  отправляются в систему через `user32.dll` (как физическая клавиатура),
  работают с любым активным плеером.
- **Реальная смена темы Windows** (светлая/тёмная) через реестр — опционально
  синхронизируется с темой острова, прав администратора не требует.
- **Monet — живая MD3-палитра из текущих обоев рабочего стола**, как
  в matugen/Android: читает файл обоев Windows, вычисляет основной цвет
  тем же алгоритмом, что использует Google (`@material/material-color-utilities`
  — Celebi-квантование + Score), и генерирует полную HCT-палитру MD3
  (primary/secondary/tertiary/surface и т.д.) отдельно для светлой и
  тёмной темы. Есть опциональное авто-обновление: остров раз в ~20 секунд
  проверяет, не изменился ли файл обоев, и пересчитывает палитру сам
  (тумблер "Авто-обновление при смене обоев" на вкладке MD3, по умолчанию
  выключен).
- **Реальные нативные уведомления Windows** (Action Center) — кнопка теста
  и автоматическое уведомление по окончании фокус-сессии.
- **Быстрые действия**: заблокировать ПК, уйти в сон, скриншот экрана
  (копия в буфер обмена + файл в `Изображения/DynamicIslandMD3`).
- **Wi-Fi / Bluetooth — экспериментальные реальные тумблеры** через
  `netsh` / `Get-PnpDevice`: запрашивают права администратора (UAC) и
  могут не сработать на части оборудования или при нестандартном имени
  адаптера (для Wi-Fi имя адаптера можно указать вручную).
- **Задачи** — чек-лист с сохранением между запусками.
- **Лаунчер** — закреплённые ярлыки приложений (выбор через системный
  диалог), запуск в один клик через `shell.openPath`. Запускаются только
  файлы, выбранные пользователем через этот диалог.
- **История буфера обмена** — **выключена по умолчанию**. Включается кнопкой
  на вкладке «Буфер» после нативного диалога согласия. Есть пауза, очистка,
  срок хранения (5 мин / 1 час / 1 день / 7 дней), по умолчанию записи живут
  только в памяти; сохранение между запусками — отдельное согласие и только
  в зашифрованном виде (Windows DPAPI через `safeStorage`). Записи, которые
  менеджеры паролей помечают как «не для истории», пропускаются.
- **Заметки** с сохранением между запусками (electron-store).
- **Фокус-таймер** (Pomodoro, 25 минут, старт/пауза/сброс, с уведомлением).
- **MD3-темы**: 6 цветовых палитр (Purple, Blue, Green, Orange, Teal, Red) +
  живой Monet, светлый/тёмный режим, прозрачность острова, автозапуск с
  Windows — всё в аккуратных карточках-секциях прямо внутри острова.
- **Анимации**: плавное раскрытие/сворачивание самого окна (не просто CSS —
  реальная анимация границ окна с easing), кроссфейд между свёрнутым и
  развёрнутым видом, плавное заполнение колец CPU/RAM, пульсирующий
  индикатор, переливающаяся плитка Monet, hover/press-отклик на кнопках
  и свотчах, лёгкая анимация появления вкладок.
- **Перетаскивание и закрепление**: остров двигается за капсулу или шапку, позиция
  запоминается (и сбрасывается, если монитор отключили); кнопка 📌 включает/выключает
  «поверх всех окон» и запоминает выбор.
- **Иконка в трее** с меню (показать/скрыть, свернуть, сбросить позицию, выход).

## Запуск локально (для разработки)

```bash
npm install
npm start
npm test        # 88 тестов, встроенный node:test, без внешних зависимостей
```

## Сборка .zip / portable .exe под Windows

```bash
npm install
npm run dist
```

Готовые файлы появятся в папке `dist/`.

## Сборка через GitHub Actions

> **Один раз перед первым пушем** сгенерируйте и закоммитьте lock-файл — CI использует
> `npm ci` и без `package-lock.json` намеренно упадёт:
> ```bash
> npm install
> git add package-lock.json && git commit -m "Add package-lock.json"
> ```

1. Создайте репозиторий на GitHub и запушьте туда это содержимое.
2. Workflow `.github/workflows/build.yml` установит зависимости через `npm ci`, прогонит
   тесты и соберёт проект на `windows-latest` автоматически при пуше в `main`/`master`, при pull request, вручную
   (`workflow_dispatch`) или по тегу `vX.Y.Z` (тогда ещё создастся Release).
3. Готовый `.zip` и `.exe` будут доступны во вкладке **Actions → артефакты
   сборки**.

## Как работает Monet

1. Остров ищет файл текущих обоев: сначала значение `WallPaper` в
   `HKCU\Control Panel\Desktop`, если не нашёл — кешированный файл
   `%APPDATA%\Microsoft\Windows\Themes\TranscodedWallpaper` (туда Windows
   сохраняет отрисованные обои в JPEG независимо от формата оригинала —
   это пригождается для слайд-шоу и Windows Spotlight).
2. Картинка уменьшается до 112×112 (тот же размер растра, что использует
   Android для извлечения цвета из обоев).
3. Пиксели квантуются алгоритмом `QuantizerCelebi`, ранжируются через
   `Score.score(...)` — получается основной ("seed") цвет.
4. Из seed-цвета через `themeFromSourceColor(...)` строится полноценная
   HCT/MD3-палитра для светлой и тёмной темы — это тот же набор формул,
   что лежит в основе Material You на Android и у matugen.

## Безопасность

Рендерер считается недоверенным. Что для этого сделано:

- **PowerShell**: пользовательский ввод не подставляется в текст скриптов. Скрипты — фиксированные
  шаблоны в `lib/powershell.js`; параметры (имя Wi-Fi адаптера, on/off) передаются как JSON в Base64
  и читаются через `ConvertFrom-Json`. Имя адаптера дополнительно проверяется по строгому regex.
  Для UAC не создаются временные `.ps1`/`.txt` файлы — результат приходит через код выхода процесса.
  Одновременно может выполняться только один запрос с повышением прав.
- **IPC**: каждый обработчик проверяет, что запрос пришёл из нашего `renderer/index.html`; настройки
  принимаются только по allowlist ключей с проверкой типов и лимитов (`lib/validation.js`); служебные
  ключи (позиция, закрепление, история буфера, список разрешённых запусков) рендерер не может ни
  читать, ни писать напрямую. Нет универсального `invoke`/`send` в preload.
- **Окно**: `sandbox: true`, `contextIsolation`, запрет `webview`, навигации и новых окон, отказ на все
  запросы разрешений, блокировка любых сетевых запросов из рендерера, DevTools только в режиме
  разработки. Строгий CSP (`default-src 'none'; script-src 'self'; style-src 'self'; …`) —
  поэтому в интерфейсе нет inline-стилей и обработчиков.
- **Лаунчер**: запуск только абсолютных путей с расширением `.exe/.lnk/.bat/.cmd`, которые пользователь
  выбрал через системный диалог.

## Тесты

`npm test` запускает 88 тестов: валидация, построение PowerShell и обработка кодов ошибок (UAC
отклонён, адаптер не найден, таймаут, нет PowerShell), история буфера (лимиты, TTL, шифруемый
round-trip), геометрия окна (мультимонитор), проверка совместимости API Electron и интеграционные
тесты настоящего `main.js` с подменённым Electron — вредоносные аргументы во все IPC-каналы.
Часть тестов — статические проверки, что sandbox/CSP/`npm ci` не будут случайно убраны.

> Тесты не запускают сам Electron. После обновления Electron проверьте руками: `npm start`,
> раскрытие/сворачивание, перетаскивание, 📌, медиа-клавиши, Wi-Fi/Bluetooth (UAC), скриншот,
> Monet. При старте `lib/compat.js` проверяет наличие всех используемых API и покажет ошибку,
> если какой-то пропал.

## Если вы обновляетесь с прошлой версии

- Старая история буфера обмена хранилась открытым текстом — при первом запуске она **удаляется**;
  новая история выключена, пока вы не включите её сами.
- Закреплённые в лаунчере приложения, добавленные в прошлой версии, нужно **добавить заново**
  (кнопкой «+ Добавить приложение»): запускаются только файлы, выбранные через диалог.

## Честные ограничения (что осталось не "по-настоящему")

- **"Не беспокоить" (Focus Assist)** переключить программно нельзя — у Windows
  нет официального публичного API/CLI для этого. Тумблер в UI декоративный,
  и это не недоработка, а ограничение самой системы.
- **Wi-Fi/Bluetooth-тумблеры экспериментальные**: требуют подтверждения UAC
  при каждом переключении, и могут не найти нужный адаптер/радиомодуль на
  нестандартном оборудовании — в таком случае тумблер откатится назад и
  покажет текст ошибки.
- **Пропуск «приватных» записей буфера** (пароли из менеджеров) работает через специальные форматы
  Windows и не проверялся на конкретных менеджерах паролей — не рассчитывайте на него как на гарантию.
- **Название/обложка трека** читаются только у плееров, которые публикуют данные в системные
  медиа-сессии Windows (Spotify, браузеры, Groove/Медиаплеер и т.д.).
- Приложение не перехватывает уведомления других программ в Action Center —
  оно может только **отправлять** свои собственные нативные уведомления.
- Авто-отслеживание обоев — это **опрос раз в ~20 секунд**, а не мгновенная
  push-реакция на событие Windows (упростил, чтобы не городить нативный
  file-system watcher поверх WinAPI). Для большинства сценариев смены
  обоев вручную/по расписанию этого достаточно.

Структура кода (main.js/preload.js/renderer) позволяет дополнять это дальше.
